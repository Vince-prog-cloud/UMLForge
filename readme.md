# UmlForge — native UML 2.5 studio for Windows

A standalone, installable C#/WPF replacement for Modelio: strict UML notation,
live UML rule validation, undo/redo, autosave with crash recovery, model explorer,
contextual properties, XMI 2.5 export and PNG export. Fully offline.
